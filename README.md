# Red Universitaria de Clubs UTE 🎓

## Descripción del Proyecto
Sistema diseñado para optimizar y automatizar la gestión de los clubs universitarios. Su propósito principal es facilitar la inscripción de los alumnos a los diferentes clubs, con un enfoque especial en brindar una experiencia de usuario intuitiva y de fácil uso para los alumnos de nuevo ingreso.

## Objetivo
Automatizar el proceso de inscripción y administración de los clubs de la universidad, centralizando la información de los estudiantes, coordinadores, horarios y catálogo de clubs en un solo sistema.

## Tecnologías y Herramientas
* **Lenguaje principal:** Python
* **Base de Datos:** MySQL
* **Procesamiento de Datos:** Archivos Excel (`.xlsx` / `.csv`)
* **Entorno de Desarrollo:** Visual Studio Code (VS Code)
* **Control de Versiones:** Git y GitHub

## Arquitectura de Datos
El sistema maneja la información a través de dos fuentes principales:
1. **Base de Datos (MySQL):** Almacena la estructura central del sistema, incluyendo:
   * Usuarios y contraseñas.
   * Administradores (Coordinadores de los clubs).
   * Catálogo de clubs disponibles.
   * Horarios de cada club.
2. **Archivos Excel:** Se utilizan para la importación de las listas de alumnos inscritos, las cuales son exportadas previamente desde los formularios de registro de los estudiantes.

## Configuración y Desarrollo
Este proyecto utiliza la integración de Git en Visual Studio Code para el control de versiones.
